# bantrab-precalificacion

Prototipo React — Módulo Precalificación Accionistas (BANTRAB / Core Access BT)

## Instalación

```bash
npm install
npm run dev
# → http://localhost:5173/precalificacion/estados
```

## Módulos

| HU       | Ruta                           | Descripción                     |
|----------|--------------------------------|---------------------------------|
| HU-61309 | /precalificacion/estados       | Estados de Precalificación      |
| HU-61310 | /precalificacion/casos         | Casos Especiales                |
| HU-61314 | /precalificacion/historica     | Calificación Histórica          |
| HU-61568 | /precalificacion/reporte       | Reporte ACCFRM0828              |

## Stack
React 19 · Vite 8 · React Router v7 · Lucide React · CSS Variables
